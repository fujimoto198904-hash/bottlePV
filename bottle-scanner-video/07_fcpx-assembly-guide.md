# 07 ─ FCPX 合成・グレーディング・書き出しガイド

DomoAIの映像（SHOT01–09）＋ Irodoriの音声 ＋ SE/BGM ＋ `assets/` グラフィックを、
Final Cut Pro X で組み上げて納品データにする手順。

---

## 1. プロジェクト設定（新規ライブラリ/プロジェクト）

| 項目 | 値 |
|------|-----|
| フォーマット | カスタム（Custom） |
| 解像度 | **1080 × 1920（Vertical）** |
| フレームレート | **30fps**（DomoAI/SE同期に有利。DomoAI出力が24/25/60fpsの場合はFCPXが自動リタイム。混在時は30に統一） |
| レンダリング | Apple ProRes 422（編集中） |
| 音声 | 48kHz |

> **fpsの判断**：DomoAI出力のfpsを確認し、**プロジェクトはそれに合わせるのが最善**。
> バラバラなら30fpsに統一（各クリップを右クリック→リタイム or 「フレームレートに合わせる」）。
> 通知音のフレーム同期があるので、最終は整数fps（30推奨）が扱いやすい。

---

## 2. トラック（レーン）構成

FCPXはマグネティックタイムライン。プライマリストーリーライン＋接続クリップで以下の層を作る。

```
[V/接続レーン 上から]
  ├ L4  CTAエンドカード（cta-endcard）／SHOT10
  ├ L3  テロップ字幕（各セリフ）
  ├ L2  ARオーバーレイ（ar-scan-overlay + notification-toast）／SHOT07
  └ L1  === プライマリ：DomoAI本編クリップ SHOT01→09（ハードカット連結） ===
[A/オーディオ 下方接続]
  ├ A1  セリフ／ナレーション（VO_* / NA_*）
  ├ A2  SE（SE_*）
  └ A3  BGM（BGM_main）＋ room tone（SE_bg_ambience）
```

## 4. トランジション / 動きの演出

- **基本はハードカット**（ドラマのテンポ）。
- SHOT06→07 の間だけ、必要なら **超短いディゾルブ（0.2s）** で「ひらめき→スキャン」を柔らかく繋いでも可。
- **暗→明の反転（0:21付近）**：SHOT07で露出/彩度を少し上げるカラー調整をキーフレームで当て、視覚的に明転させる。
- CTA（SHOT10）：**フェードイン**（クロスディゾルブ 0.4s）＋ 要素ごとの出し（`06`参照）。
- 任意：オチのSHOT09で **わずかなスローモーション（90%）** にすると余韻が出る。

## 5. カラーグレーディング（DomoAIクリップの質感統一）

DomoAIの各クリップは色味がばらつくため、**統一グレード**で1本の作品にまとめる。

1. 各クリップに **バランス調整（自動ホワイトバランス）** を軽く当てる
2. マスターの「ルック」を作る（調整の基準）：
   - **暖色基調**：ハイライトをアンバー方向、シャドウをわずかにティール（映画的コントラスト）
   - シャドウを軽く持ち上げすぎない（Barの締まった黒を残す）
   - 彩度：+5〜10%程度（過飽和は避ける）
3. **明暗設計を反映**：
   - SHOT01–06：露出やや低め・コントラスト強めで緊張感
   - SHOT07以降：露出を上げ、彩度・暖かみを足して解決感
4. 仕上げに軽い **ビネット** と **フィルムグレイン** で全クリップの質感を接着
5. 可能なら共通LUTを1つ作り、全クリップに適用してから微調整（最速で統一できる）

## 6. 書き出し（納品）設定

| 項目 | 値 |
|------|-----|
| フォーマット | Computer / Video and Audio |
| コーデック | **H.264**（SNS汎用）または HEVC(H.265) |
| 解像度 | 1080 × 1920 |
| フレームレート | プロジェクトと同一（30fps） |
| ビットレート | 15〜20 Mbps（高画質・SNS圧縮に耐える） |
| 音声 | AAC 256〜320 kbps / 48kHz |
| ラウドネス | -14 LUFS 目安 / True Peak ≤ -1dBTP |
| カラースペース | Rec.709（SDR） |

- 納品用にマスター（ProRes 422 HQ）も1本書き出しておくと再編集・別尺展開が楽。
- SNS別に微調整版が要る場合（IG/TikTok/Shorts）、セーフエリアだけ確認して同マスターから書き出す。

## 7. 最終QCチェックリスト
- [ ] 尺がぴったり35秒前後か（間延び・切れなし）
- [ ] 全セリフと字幕が同期しているか
- [ ] 通知音（ピロン）とトーストSVGが**同フレーム**か
- [ ] 暗→明の反転が0:21で気持ちよく決まっているか
- [ ] キャラの顔がショット間で破綻していないか（破綻ショットは差し替え）
- [ ] 上下セーフエリアにUI/重要情報が被っていないか
- [ ] ラウドネス -14 LUFS / ピーク -1dB 以下か
- [ ] CTAのロゴ・コピー・「プロフィールから」導線が明瞭か
- [ ] 音声オフでも内容が伝わるか（字幕だけで理解できるか）

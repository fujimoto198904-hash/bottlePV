# Bottle Scanner ─ ショートドラマ制作パッケージ（35秒 / 9:16 縦型 / 実写シネマティック）

このフォルダは、DomoAI（映像生成）＋ Irodori（音声生成）＋ Final Cut Pro X（最終合成）で
「Bottle Scanner」プロモ動画を**納品クオリティ**で仕上げるための素材・指示書・管理システム一式です。

> 制作者ワークフロー：**DomoAI（ブラウザ）で映像 → Irodori（ローカル）で音声 → FCPX で合成・納品**
> このパッケージは「その3ツールを迷わず回すための設計図と実素材」です。

## 1. 確定フォーマット仕様

| 項目 | 値 | 備考 |
|------|-----|------|
| アスペクト比 | **9:16 縦型** | Instagram Reels / TikTok / YouTube Shorts |
| 解像度 | **1080 × 1920 px** | DomoAI・FCPX 共通 |
| フレームレート | **30fps** | SNS標準・通知音のフレーム同期が楽（→ §FCPX参照） |
| 尺 | **35秒**（0:00–0:35） | 5シーン・10ショット構成 |
| ビジュアル | **実写シネマティック（photoreal）** | 高級Barの実写ドラマ調 |
| 音声言語 | **日本語** | Irodori生成 |
| カラー基調 | アンバー暖色 × ミント/シアン（スキャナのテック色） | §01・ロゴ参照 |
| 安全域 | 上下 各220px はUI/指を避ける | 縦型SNSの被り対策（→ §06） |

## 2. 標準ワークフロー（この順で回すのが最短）

```
STEP 1  企画確認    → 01_production-bible.md を読み、キャラ・トーンを頭に入れる
STEP 2  声を作る    → 04_irodori-voice-script.md の通りに Irodori で全ラインを生成
                      → voice-exports/ に命名規則どおり保存（尺の実測ができる）
STEP 3  映像を作る  → 03_domoai-prompts.md の keyframe画像 → I2V で各ショット生成
                      → domoai-exports/ に SHOT番号で保存
STEP 4  音を集める  → 05_se-bgm-cue-sheet.md でSE/BGM/通知音をそろえる
STEP 5  文字を用意  → assets/ のSVGと 06_graphics-telop-spec.md の字幕テキスト
STEP 6  合成        → 07_fcpx-assembly-guide.md のタイムライン表どおりに並べる
STEP 7  グレーディング→ 全DomoAIクリップに統一LUT/グレードを当てて質感をそろえる
STEP 8  書き出し    → 07 の書き出し設定で納品データ化
```

> **プロデューサーからの推奨順の理由**：先に「声（STEP2）」を確定させると各ショットの
> **実尺**が確定し、DomoAIで作る映像の長さ（4〜5秒）を無駄なく設計できます。
> 声が3秒で終わるショットに5秒の映像を作るとクレジットが無駄になるため、**声→映像**の順が効率的です。

## 3. 命名規則（FCPXでの取り違え防止）

映像・音声・グラフィックは、以下の規則で保存すると FCPX 上で迷いません。

| 種別 | 命名 | 例 |
|------|------|-----|
| DomoAI映像 | `SHOT{番号}_{内容}.mp4` | `SHOT03_kenji-checking.mp4` |
| Irodori音声 | `VO_S{シーン}_{キャラ}_{通番}.wav` | `VO_S1_manami_01.wav` |
| ナレーション | `NA_S{シーン}_{キャラ}_{通番}.wav` | `NA_S2_kenji_01.wav`（心の声） |
| SE | `SE_{時刻}_{内容}.wav` | `SE_0021_notify-piron.wav` |
| BGM | `BGM_{区間}.wav` | `BGM_main.wav` |
| グラフィック | `assets/` 内のSVG（そのまま） | `cta-endcard.svg` |

## 4. このパッケージが「納品クオリティ」のためにやっていること

- **キャラ一貫性**：3人の外見を固定した「キャラトークン」を全プロンプトに共通適用（実写AIドラマ最大の難所を潰す）
- **共感の設計**：シーン2の「焦り」はコミカルに寄せすぎず“新人あるある”のリアルさで描く演出指定
- **気持ちよさのギャップ**：シーン3で暗→明のライティング反転＋軽快SEで「見つかった瞬間」のカタルシスを作る
- **小さなオチ**：マナミの「頼りになる」でケンジの成長・信頼構築を締める
- **ブランド精度**：AR UI・ロゴ・CTAはAI任せにせず実データSVGで作成（フォント・色・レイアウトを完全管理）

## 5. 別バージョン展開（同じシステムで作れます）

台本の「他バージョン（ベテランが後輩に自慢するver／満席の忙しい夜ver など）」も、
このパッケージの**キャラトークン・スタイルサフィックス・命名規則をそのまま流用**して量産できます。
`01_production-bible.md` の §キャラクターシートと §スタイルサフィックスが共通アセットです。

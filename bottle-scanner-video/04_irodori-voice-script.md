# 04 ─ Irodori 音声台本（日本語）

Irodori（ローカル音声生成）にそのまま入力できる形式。各ラインに **読み・感情・速度・間** の演出指定つき。
先に全ラインを生成して `voice-exports/` に保存すると、各ショットの**実尺**が確定し映像設計が正確になる（→ `README.md §2`）。

> **入力のコツ**
> - 漢字の読み違い防止に **読み（かな）** を併記。Irodoriで意図と違う読みになる場合はかな入力に置換。
> - `…` は**タメ／間**。Irodoriに「間」機能があれば無音を挿入、無ければ句読点・改行で調整。
> - 感情表現は「セリフの前後の芝居」を映像側でも担うので、声は**やりすぎない**（実写ドラマのリアリティ）。
> - 速度・ピッチは目安。キャラの一貫性を優先し、全ラインで同キャラは同設定に。

## 収録・書き出しチェックリスト
- [ ] サンプルレート **48kHz / 24bit（またはIrodori最高品質）** で書き出し（FCPX標準に合わせる）
- [ ] 無音の頭・尻を軽くトリム（FCPXで配置しやすく）
- [ ] ノーマライズは **-3dB 目安**（クリップ回避）。最終ラウドネスはFCPXで調整
- [ ] 各キャラの声・速度・ピッチ設定を**メモして統一**（別バージョン制作でも同設定を再利用）
- [ ] `voice-exports/` に命名規則どおり保存
- [ ] 全ラインの実尺を測り、`02_shot-list.md` の尺目安と照合（大きくズレたらショット尺を調整）

## 音声の実尺 → 映像尺への反映（プロデューサーの要点）
セリフの実尺が確定したら、各ショットのDomoAI生成尺を「セリフ実尺 + 前後の余白（0.5〜1.0秒）」で決めると、
無言の間延びも、セリフが切れる事故も防げる。特に SHOT03（心の声）と SHOT09（オチ）は**間**が命なので、
声を先に置いてから映像尺を合わせること。

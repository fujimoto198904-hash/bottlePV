# alt-versions/

ベース版（本編35秒）と**同じキャラ・世界観・ブランド・通知音**を流用した別バージョン台本。
共通アセット（キャラトークン／スタイルサフィックス／SVG／SE）はベースをそのまま使う。

| ファイル | 版 | 主役 | ひとこと |
|---------|-----|------|---------|
| `altA_veteran-brag.md` | ベテランが後輩に自慢する版 | タカシ（店長） | 「使えるモンは、使わなきゃな」＝道具で誰でもデキる人に |
| `altB_busy-night.md` | 満席の忙しい夜版 | アンサンブル | ピロン連打のテンポ。忙しい夜こそ差が出る |
| `altC_female-manager.md` | 女性店長版 | ミサキ（女性店長） | 大人の余裕とホスピタリティ。「一本、忘れませんよ」 |
| `altD_anniversary-surprise.md` | 記念日サプライズ版 | ケンジ＋カップル客 | 泣ける寄り。「大切な一本を、大切な瞬間に。」 |
| `altE_english-narration.md` | 英語ナレーション版 | ナレーション（映像流用） | 海外/インバウンド向け。映像は再撮影不要 |

各ファイルは「尺配分・Irodoriセリフ表・DomoAIプロンプト差分・音/演出メモ」を収録。
制作手順はベースと同じ（声→映像→音→文字→FCPX）。命名規則は `VO_altA_...`〜`VO_altE_...` で分ける。

## 各版の字幕（`../subtitles/`）
- `altA_veteran-brag_ja.srt` / `altB_busy-night_ja.srt` / `altE_english.srt`
- altC・altDの字幕は、各台本のセリフ表からベース版SRTと同じ書式で追加可能（依頼ください）。

> さらに別方向（記念日/季節キャンペーン/多言語版 等）も同システムで追加可能。

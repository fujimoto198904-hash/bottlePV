# alt-versions/

ベース版（本編35秒）と**同じキャラ・世界観・ブランド・通知音**を流用した別バージョン台本。
共通アセット（キャラトークン／スタイルサフィックス／SVG／SE）はベースをそのまま使う。

| ファイル | 版 | 主役 | ひとこと |
|---------|-----|------|---------|
| `altA_veteran-brag.md` | ベテランが後輩に自慢する版 | タカシ（店長） | 「使えるモンは、使わなきゃな」＝道具で誰でもデキる人に |
| `altB_busy-night.md` | 満席の忙しい夜版 | アンサンブル | ピロン連打のテンポ。忙しい夜こそ差が出る |

各ファイルは「尺配分・Irodoriセリフ表・DomoAIプロンプト差分・音/演出メモ」を収録。
制作手順はベースと同じ（声→映像→音→文字→FCPX）。命名規則は `VO_altA_...` / `VO_altB_...` で分ける。

> さらに別方向（女性店長版／記念日サプライズ版／英語ナレーション版 など）も同システムで追加可能。

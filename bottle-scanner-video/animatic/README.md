# animatic/ ─ タイミング検証用アニマティック（35秒 previz）

`index.html` をブラウザで開くと、**35秒の流れを実際に再生**できます（仮映像のスレート＋字幕＋合成音）。
実映像（DomoAI）・実音声（Irodori）が出来たら差し替えていく“土台”です。

## 何ができる
- ▶ 再生：35秒を通しで再生。ショットの尺・字幕の出入り・AR発見の瞬間・CTAのタイミングを体感確認
- タイムラインをクリックで任意の位置へシーク（`#t=21` のようにURLで時刻指定も可）
- **合成音**：Web Audioで生成した緊張ティック（8–18s）／スキャンスイープ（20.6s）／**ピロン（21.0s）**／
  解決パッド（24–31s）／ブランドチャイム（32s）が鳴る（音は再生ボタンから）

## 使い方（制作フローでの位置づけ）
1. まずこれで**尺とテンポの当たり**を掴む（クライアント合意にも使える）
2. DomoAIで各ショットを作ったら、FCPXでスレートを実映像に差し替え
3. Irodoriの声・本番SEに差し替え（ピロンは `../assets/audio/SE_0021_notify-piron.wav` を利用）

> これは仮動画（previz）です。最終尺・カット感の設計図として使ってください。
> ブラウザ内で完結する自己完結HTML（外部通信なし）。

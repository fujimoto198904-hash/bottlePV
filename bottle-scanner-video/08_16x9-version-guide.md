# 08 ─ 16:9 併用版ガイド（1920×1080）

9:16縦型を主軸に、**YouTube通常動画・展示会・店頭サイネージ用の16:9横型**も同じ台本・素材で出すための追記。
台本・セリフ・SE・BGM・通知音・キャラは**すべて共通**。変わるのは**構図（画角）とグラフィックの縦横**だけ。

---

## 1. 設定変更点

| 項目 | 9:16版 | 16:9版 |
|------|--------|--------|
| 解像度 | 1080×1920 | **1920×1080** |
| DomoAI Aspect | 9:16 | **16:9** |
| FCPXプロジェクト | 1080×1920 | **1920×1080** |
| CTAエンドカード | `assets/cta-endcard.svg` | **`assets/16x9/cta-endcard-16x9.svg`** |
| ARオーバーレイ | `assets/ar-scan-overlay.svg` | **`assets/16x9/ar-scan-overlay-16x9.svg`** |

| 字幕セーフエリア | 下から約420px | 下から約120px（横型はUI被りが少ない） |

## 2. 各ショットの横型リフレーム（DomoAIは16:9で再生成）

> 縦型を単純クロップすると窮屈になるため、**16:9では引き（横の情報量）を活かす**構図に変える。
> プロンプトはベース `03_domoai-prompts.md` の各ショットを流用し、下記の「画角ワード」を差し替える。

| SHOT | 9:16の狙い | 16:9での構図変更 |
|------|-----------|-----------------|
| 01 | 縦にマナミ＋奥のボトル壁 | 横位置で**カウンターの奥行き**を見せる。マナミを左1/3、右にボトル壁のボケ |
| 02 | 縦にケンジ＋壁の圧 | ケンジを右、左にワイドな**ボトル壁の広がり**で“途方に暮れる”量感 |
| 03 | 手元＋横顔の縦クロース | 横で**手元（左）と焦る表情（右）を同一フレーム**に。関係が見える |
| 04 | マナミ縦クロース | 横で**マナミ（右）とケンジの背中のボケ（左）**を同居させ状況説明 |
| 05 | タカシ縦 | 横で**タカシ（左）とケンジ（右奥ボケ）**の視線の線を作る |
| 06 | ひらめき縦クロース | 横でもクロースのままOK。左右に余白でスマホを構える動き |
| 07★ | 肩越し縦 | 横で**ケンジ（左）＋棚（右）**を並べ、ARオーバーレイを右側の棚に重ねる |
| 08 | 提供の縦ミディアム | 横で**棚→カウンターへの横移動**を1フレームで見せる（動きが映える） |
| 09 | マナミ笑顔＋奥タカシ | 横で**マナミ（左）とタカシ（右）を左右に**配置し、両方の反応を同時に見せる |
| 10 | CTA縦 | `assets/16x9/cta-endcard-16x9.svg`（アイコン左＋コピー右のレイアウト） |

**差し替える画角ワード例**（keyframe冒頭）:
- 9:16：`Cinematic medium shot ... vertical 9:16 composition`
- 16:9：`Cinematic wide/medium shot ... horizontal 16:9 composition, cinemascope framing`
- ネガティブ末尾の `vertical` 依存を外し、`horizontal 16:9` を明示。

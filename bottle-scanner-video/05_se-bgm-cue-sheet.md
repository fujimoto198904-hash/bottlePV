# 05 ─ SE / BGM キューシート

音は「焦り → ひらめき → 爽快」の感情曲線を作る主役。特に **0:21 の通知音「ピロン」がヒーローSE**。
素材は使用許諾フリーの音源ライブラリ（Epidemic Sound / Artlist / 効果音ラボ 等）から、下記の**検索ワード**で探すと近い。

> 記号：`◎`＝必須のキモ音 ／ `○`＝あると質が上がる ／ `△`＝任意

---

## 1. BGM 設計（1曲を区間で強弱、または2曲つなぎ）

**基本方針**：1曲を通して敷き、シーンごとに音量・帯域で表情をつけるのが最も自然。
ジャンルは **落ち着いたラウンジ／ジャズ寄り × ほんのりテック**。

| 区間 | 時刻 | 表情 | 具体指定 |
|------|------|------|---------|
| イントロ | 0:00–0:08 | 上質・静か | スパースなピアノ＋ウッドベース。低音量で空気づくり |
| テンション | 0:08–0:18 | 焦り（コミカルすぎない） | 軽いパルス/刻みを足し、じわっと緊張。音量やや上げ |
| リフト | 0:18–0:21 | ひらめき | 小さな上昇フレーズ（ハープのグリス等）で気分転換 ◎ |
| 上昇 | 0:21–0:24 | 解決の予感 | 明るい和音へ転換。通知音と重ねてカタルシス |
| 解決 | 0:24–0:32 | あたたかい自信 | 軽快で温かいグルーヴ。幸福感 |
| ブランド締め | 0:32–0:35 | 想起 | 解決和音で締め、最後にブランドスティング |

- **検索ワード**：`upscale lounge jazz`, `light comedic tension`, `feel good discovery`, `warm corporate uplifting`, `brand logo sting`
- **保存名**：`BGM_main.wav`（1曲通し運用の場合）／ 2曲なら `BGM_A_tension.wav` `BGM_B_resolve.wav`
- **ラウドネス目安**：BGMは会話の下。会話区間で **-18〜-20 LUFS 程度**まで下げ、無会話区間で持ち上げる（ダッキング）

## 3. ◎ヒーローSE「ピロン」通知音スペック（0:21）

このSEが**気持ちよさの決定打**。以下の条件で選定/微調整する。

| 項目 | 指定 |
|------|------|
| 印象 | 明るい・軽快・親しみやすい「成功！」感。高級感を壊さない上品な粒 |
| 音程 | **2音の上行**（例：ミ→ソ、または ソ→ド）。上がって終わる＝ポジティブ |
| 音色 | クリーンなベル／マリンバ／グラス系。角の立たない丸い音 |
| 長さ | **0.35〜0.5秒**。短く歯切れよく |
| 余韻 | ほんの少しのリバーブ。伸ばしすぎない |
| 音量 | BGMの上に**はっきり抜ける**。この瞬間だけBGMを一瞬ダッキング |
| 画面同期 | `assets/notification-toast.svg` が出るフレームと**完全一致**（30fpsなのでフレーム単位で合わせる） |

> **統一メモ**：この通知音は「Bottle Scannerのサウンドロゴ」になる。別バージョン動画でも**同じ音**を使い、
> ブランド記憶に残す。可能なら実機アプリの通知音と一致させる。

## 4. 音声処理メモ（FCPXでの仕上げ）

- **心の声（NA_S2_kenji_01）**：軽いショートリバーブ＋ローカット/ハイシェルフで「内語」感。他のセリフより少しドライで近接に
- **タカシの小声**：近接感を出しつつ音量控えめ。BGMを少し譲る
- **通知音の瞬間**：BGMを 0.2秒だけ -6dB ダッキング → ピロンを立たせる
- **全体ラウドネス**：SNS納品は **-14 LUFS 前後**を目安（プラットフォーム標準）。ピークは -1dBTP 以下

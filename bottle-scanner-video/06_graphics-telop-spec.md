# 06 ─ グラフィック / テロップ仕様

文字とUIグラフィックの仕様。**AR UI・ロゴ・CTA は `assets/` の実データSVGを使用**（AI生成に頼らずブランド精度を確保）。
字幕テロップはFCPXのタイトル機能で下記スタイルに沿って作る。

---

## 1. セーフエリア（9:16・1080×1920）

| 領域 | ピクセル | 用途 |
|------|---------|------|
| 上部セーフ余白 | 上から 220px | プラットフォームUI（アカウント名等）と被らせない |
| 下部セーフ余白 | 下から 320px | いいね/コメント/キャプションUIと被らせない。**字幕はこの上端付近に** |
| 左右セーフ余白 | 各 60px | 見切れ防止 |
| 字幕基準ライン | 下から約 **420px** の帯 | 全字幕をこのラインに揃える |

---

## 2. 字幕（バーンイン）スタイル

SNSは音声オフ視聴が多いため、**全セリフに字幕を推奨**。

| 項目 | 指定 |
|------|------|
| フォント | 日本語ゴシック太め（例：**Noto Sans JP Bold** / ヒラギノ角ゴ W6）。可読性優先 |
| サイズ | 本文 約 **64〜72px**（1080幅基準） |
| 色 | オフホワイト `#F5EFE6` |
| 縁取り/影 | 黒フチ 4〜6px ＋ ソフトシャドウ（暗背景でも明背景でも読める） |
| 位置 | 下から約420pxの字幕ライン。中央揃え |
| 話者色分け（任意） | ケンジ＝白 ／ マナミ＝ややアンバー寄り ／ タカシ＝ややグレー、で微差をつけると誰の声か伝わる |
| 出入り | セリフに合わせてカット単位で切替（ふわっと0.1sフェードでも可） |

### 字幕テキスト（コピペ用・時刻付き）
| 時刻 | 話者 | 字幕テキスト |
|------|------|-------------|
| 0:01 | マナミ | いつものボトル、お願いできる？山崎の… |
| 0:05 | ケンジ | あ、はい！少々お待ちください…！ |
| 0:09 | ケンジ（心の声） | え、どれだっけ…先週も探したのに…（※斜体や（　）で内語表現） |
| 0:16 | タカシ | ケンジ、大丈夫か？ |
| 0:22 | ケンジ | …あった！ |
| 0:25 | ケンジ | お待たせしました、山崎です |
| 0:29 | マナミ | 早いね、ケンジ君。頼りになる |

> 心の声は字幕を **（　）括弧＋斜体** など見た目で区別すると「声に出していない」と伝わる。

## 3. AR スキャンUI（SHOT07・0:21–0:24）

**`assets/ar-scan-overlay.svg`** をスマホ画面に合わせてFCPXで配置・スケール。

- 構成：四隅のフォーカスブラケット＋中央のスキャンライン＋ターゲットのボトルにロックするレティクル
- アクセント色：ミント/シアン `#3FE0C5`
- アニメーション（FCPX側）：
  1. 0:21.0 ブラケットがフェードイン＋スキャンラインが上→下に一度スイープ（`SE_0020_scan-sweep` と同期）
  2. 0:21.5 レティクルが目的ボトルに「ピタッ」と収束（スケールダウンして固定）
  3. 0:21.5 **`assets/notification-toast.svg`** がポップイン（`SE_0021_notify-piron` と**同フレーム**）
- トースト文言：**「山崎 12年 ✓ ボトルキープ確認」**（下段に小さく「棚 A-7」など位置情報風で説得力UP）

## 4. CTA エンドカード（SHOT10・0:32–0:35）

**`assets/cta-endcard.svg`** をフェードイン。FCPXでの出しの順序：

1. 0:32.0 背景フェードイン（暗チャコール＋アンバー/ミントのボケ）
2. 0:32.3 ロゴ `Bottle Scanner`（スキャンbrackets付きワードマーク）がスケールイン＋`SE_0032_brand`
3. 0:32.8 メインコピー「探す時間を、おもてなしの時間に。」がフェード＋軽い上スライド
4. 0:33.6 サブ「詳しくはプロフィールから」＋上向き矢印がフェード
5. 0:35.0 終了

- フォント：見出しは力強い日本語ゴシック（Noto Sans JP Black 等）
- コピー色：オフホワイト `#F5EFE6`、アクセントに アンバー `#E8B451` / ミント `#3FE0C5`

---

## 5. ロゴ・ワードマーク

**`assets/logo-lockup.svg`**（単体ロゴ）を用意。ブランドの意味：
- ボトルのシルエット × スキャンのブラケット＝「ボトルを、スキャンする」
- 暖色アンバー（おもてなし）× ミント（テック）の2色でブランドストーリーを表現

FCPX以外（サムネ、プロフィール画像、他バージョン動画）にも流用可。

---

## 6. 提供素材一覧（`assets/`）
| ファイル | 用途 | 使用ショット |
|---------|------|-------------|
| `logo-lockup.svg` | 単体ロゴ／ワードマーク | 汎用・CTA |
| `ar-scan-overlay.svg` | ARスキャン枠（全画面オーバーレイ） | SHOT07 |
| `notification-toast.svg` | 「ピロン」成功トースト | SHOT07 |
| `cta-endcard.svg` | エンドカード（全画面 1080×1920） | SHOT10 |

> SVGはベクターなので拡大しても劣化しない。FCPXが直接読めない場合は、
> ブラウザで開いて**PNG（1080×1920, 背景透過が必要な物は透過PNG）**に書き出してから読み込む。
> （書き出し手順は各SVG冒頭のコメント＆ `dashboard/index.html` からプレビュー可能）
